# ハンズオン仕様：問い合わせ優先度機能

## 1. 要件
問い合わせに優先度を設定して管理したい。

## 2. 仕様
| 観点 | 仕様 |
|---|---|
| 優先度 | 高・中・低 |
| 登録 | 問い合わせ登録時に選択可能 |
| 表示 | 問い合わせ一覧に優先度を表示 |
| 絞り込み | 優先度で絞り込み可能 |
| 初期状態 | すべて表示 |
| 既存検索 | 変更しない |
| ステータス絞り込み | 既存機能を維持 |

## 3. 受入基準
- [ ] 高・中・低で登録できる
- [ ] 登録した優先度が一覧に表示される
- [ ] 各優先度で絞り込みできる
- [ ] 「すべて」で全件表示できる
- [ ] キーワード検索が正常に動く
- [ ] ステータス絞り込みが正常に動く

## 4. 制約
- 既存の設計・命名規則を維持する。
- 変更は必要最小限とする。
- 関係のないリファクタリングは行わない。
- H2の既存データは開発用であり、DBマイグレーションツールの導入は今回の対象外とする。
