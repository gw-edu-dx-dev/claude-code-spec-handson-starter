# 問い合わせ管理アプリ - Claude Code 仕様駆動開発ハンズオン

このプロジェクトは、Claude Codeで「仕様から始めるAI開発」を体験するためのスターターです。
開始時点では **問い合わせ優先度機能は未実装** です。

## できること（開始時点）
- 問い合わせ登録
- 問い合わせ一覧表示
- キーワード検索（件名・内容）
- ステータス絞り込み（未対応・対応中・完了）

## ハンズオンで追加すること
`SPEC.md` の仕様に従って「優先度（高・中・低）」を追加します。

開始前に `SETUP.md` を実施してください。

## 前提環境
- Java 21
- Maven 3.9+
- Claude Code

## 起動
```bash
mvn spring-boot:run
```

ブラウザで `http://localhost:8080/inquiries` を開いてください。

## テスト
```bash
mvn test
```

## 推奨の進め方
1. `CLAUDE.md` と `SPEC.md` を読む
2. Claude Codeに既存コードの調査を依頼する
3. 影響範囲を分析する
4. Planを作成し、人間がレビューする
5. Planを承認して実装する
6. テスト・差分レビュー・受入基準照合を行う
7. 問題があれば限定的に修正する
8. 最終レビューとPR説明文作成を行う

具体的なプロンプトは `HANDSON.md` を参照してください。
