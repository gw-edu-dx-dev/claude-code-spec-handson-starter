# Claude Code 作業ルール

このリポジトリは研修用の問い合わせ管理アプリです。

## 開発方針
- 仕様・受入基準を最優先する。
- 実装前に既存コードを調査し、影響範囲を整理する。
- 承認された Plan の範囲だけを変更する。
- 変更は必要最小限にする。
- 既存の設計・命名規則を維持する。
- 関係のないリファクタリングを行わない。
- 既存のキーワード検索・ステータス絞り込みを壊さない。
- 実装後は関連テストと既存テストを実行する。

## 技術スタック
- Java 21
- Spring Boot 3.3.x
- Spring MVC / Thymeleaf
- Spring Data JPA
- H2 Database
- Maven

## 主な構成
- `domain`: エンティティ・列挙型
- `repository`: DBアクセス
- `service`: ユースケース
- `web`: Controller・Form
- `templates`: 画面
- `test`: 回帰確認を含む自動テスト

## 禁止事項
- 仕様にない機能追加
- 大規模な構造変更
- フレームワークやライブラリの置き換え
- テストを削除して通す行為
